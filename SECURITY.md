# Security Policy

## Reporting security vulnerabilities

Please report any security issue by emailing **security@topherbot.dev**. Do not create a public issue. Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will acknowledge receipt within 48 hours and aim to provide a fix as quickly as possible.

## Supported Versions

Only the latest stable release (currently `v0.1.0`) receives security updates.
